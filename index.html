What is Scroll Swap?

Scroll Swap is an app-first route for exchanging tokens on Scroll through Zebra, a decentralized exchange built on Scroll. Scroll is EVM-compatible, so confirm network, token contracts, and transactions with Scrollscan before signing.

How Scroll Swap works

  1. Open the appUse the button to enter Zebra's trading interface from the verified destination.
  2. Connect on ScrollConnect an EVM wallet and confirm it is set to Scroll Mainnet before selecting assets.
  3. Choose the pairPick the input and output tokens, then verify symbols against contract addresses when needed.
  4. Review and confirmCheck price impact, slippage, minimum received, approvals, and the final wallet prompt.

Scroll Swap FAQ

What is scroll swap?

scroll swap is the user intent to exchange tokens on Scroll; this page routes to Zebra's app for an on-chain DEX trade and keeps the key safety checks visible.

Is scroll swap the official Scroll app?

No. Scroll is the network, and Zebra is a third-party DEX built on Scroll; verify app.zebra.xyz before connecting a wallet.

Which wallet do I need for scroll swap?

Use an EVM wallet set to Scroll Mainnet; Scroll docs list chain ID 534352 and ETH as the currency symbol.

Why can a scroll swap fail?

Common causes are too little liquidity, tight slippage, price movement before execution, insufficient ETH for gas, or selecting the wrong token contract.

How should I check a scroll swap after signing?

Open the transaction hash on Scrollscan and review the status, logs, and token transfers; wallet balances can lag behind the explorer.
